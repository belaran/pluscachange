README
====

This repository contains the markdown based content for the website for the website [shadowrun-jdr.fr](https://shadowrun-jdr.fr). Its main function is to act as a welcome page and provided URLs to other resources related to the French speaking Shadowrun communities (such as the [ShadoWiki](https://wiki.shadowrun-jdr.fr).

Pull Requests to add relevant links, fixed typos, and so on are very much welcome.
